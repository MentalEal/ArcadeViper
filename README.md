# Arcade Viper

Ein Snake-Spiel als Windows-Desktop-App (Electron).

## Starten

Voraussetzung: Node.js und Git (`winget install OpenJS.NodeJS.LTS` und `winget install Git.Git`).

In CMD:

```
git clone https://github.com/MentalEal/ArcadeViper.git
cd ArcadeViper
npm install
npm start
```

## Update holen

```
git pull
npm start
```
